# Rule-Based AI Chatbot 🤖

A simple, lightweight CLI chatbot built with Python that interacts with users based on predefined conditional logic.

---

## ✨ Features

* Input Normalization: Cleans user inputs (lowercase & trimmed spaces) for precise matching.
* Predefined Responses: Handles greetings, identity, status, and purpose inquiries.
* Fallback System: Provides a default guide message for unrecognized commands.
* Easy Exit: Session closes smoothly using exit or quit.

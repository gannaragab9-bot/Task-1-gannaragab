Rule-Based AI Chatbot 🤖

  A lightweight, efficient, and deterministic command-line chatbot built with Python. This chatbot operates based on defined rule-based guardrails to ensure precision, reliability, and structured communication.

📖 Overview

  The Rule-Based AI Chatbot is a console-based application designed to demonstrate the fundamentals of conditional logic and natural language input handling. By utilizing text preprocessing techniques (lowercasing and whitespace stripping), it ensures a reliable user experience within a defined scope of interactions.

✨ Features

  Deterministic Logic Engine: Responds with 100% efficiency using precise, rule-based matching.
  Smart Input Cleaning: Automatically handles variations in user input by stripping trailing spaces and converting text to lowercase.
  Communication Guardrails: Provides safe, predefined responses to guide the conversation.
  Clean Exit System: Allows users to gracefully terminate the session at any time using simple commands (exit or quit).
  Tech Stack

Language: Python 3.x
Paradigm: Procedural Programming & Rule-Based Logic
